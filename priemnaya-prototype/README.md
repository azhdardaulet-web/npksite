# Прототип: страница «Общественная приёмная»

Статический HTML-прототип для визуальной сверки перед реализацией в React.
Открой `index.html` в браузере — переключатель формата, слайдер отзывов
и выбор филиала кликабельны.

## Что внутри

- `index.html` — весь прототип, один файл, без зависимостей
- `filialy.md` — исходные данные 20 филиалов (уже встроены в JS-массив
  `branches` внутри index.html как рабочие данные для прототипа)

## Как переносить в проект

Комментарии `<!-- data: ... -->` в разметке указывают, откуда должны
приходить данные в реальном приложении (таблицы/поля Supabase из
docs/PRAVKI.md и docs/VIDEOPRIEM.md) — используй их как чек-лист при
подключении к БД.

Ключевые интерактивные элементы, которые нужно воспроизвести в React:

1. **Переключатель формата** (`setFormat()`) — «Письменное обращение»
   показывает блок загрузки файлов и образцы обращения, «Видеоприём»
   скрывает их и показывает подсказку про согласование времени.
2. **Слайдер отзывов** — бесшовный бесконечный скролл (список отзывов
   продублирован дважды + CSS-анимация), пауза при наведении курсора.
3. **Выбор филиала** — карточка с адресом/контактами скрыта, пока
   пользователь не выберет город из списка; пустые поля (нет
   телефона/председателя — см. filialy.md) не отображаются.

## Не входит в прототип (сделать отдельно)

- Реальные файлы образцов обращения (PDF на казахском и русском) —
  сейчас это просто кликабельные карточки-заглушки
- Настоящее фото/скриншот видеозвонка вместо плейсхолдера
- Мини-карта филиала (сейчас плейсхолдер) — использовать существующий
  компонент карты с сайта
