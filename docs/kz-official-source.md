# Дополнительный официальный KZ-источник

Дата сверки: 20.07.2026.

По разрешению заказчика казахские страницы официального сайта НПК используются как вторичный вычитанный источник. Первичным остаётся `content/kzversiontext.md`.

## Страницы

| Адрес | Что можно сверять | Ограничения |
|---|---|---|
| https://halykpartiyasy.kz/kz/partiya-turaly | Описание, методы, структура, цель и направления деятельности партии | В меню и футере есть RU-строки |
| https://halykpartiyasy.kz/kz/frakciya-turaly | Описание фракции, задачи и список результатов | Числовые показатели могут устареть; меню частично смешанное |
| https://halykpartiyasy.kz/kz/zhobalar | Заголовок и вводная строка раздела проектов | На странице нет полных текстов карточек текущего сайта |
| https://halykpartiyasy.kz/kz/partiya-basshylyy | Актуальное написание имён и должностей | Не содержит полных биографий; состав нужно сверять с CMS |
| https://halykpartiyasy.kz/kz/partiya-tarihy | Тексты событий 2011, 2016, 2020, 2021 и 2022 годов | Нет более новых событий; есть RU-фрагменты в общей обвязке |

## Правила переноса

1. Не изменять казахский текст и не переводить его заново.
2. Переносить только при точном смысловом совпадении с текущим RU-контентом.
3. Не переносить RU-строки, ошибки старого сайта и устаревшие факты.
4. Каждая новая пара добавляется в `docs/kz-mapping.md` с URL в качестве источника.
5. Конфликты и несовпадения остаются в `docs/kz-missing.md` с RU-фолбэком.
