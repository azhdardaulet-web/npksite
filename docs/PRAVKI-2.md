## Часть 1. Технические решения

**A1, острые углы.** Не выпиливать `rounded-*` по 200 файлам руками Claude Code — это дорого и он что-нибудь пропустит. Правильно: в tailwind.config переопределить шкалу borderRadius так, чтобы все существующие классы (`rounded`, `rounded-lg`, `rounded-xl`...) рендерились в 0. Одна правка конфига — весь сайт с острыми углами, включая будущие компоненты. Останутся только инлайн-стили и произвольные значения (`rounded-[10px]`) — их добить grep-аудитом.

**A3, эталон цвета.** Красный из логотипа объявляется единственным значением токена `--accent` (светлая и тёмная тема — свои согласованные оттенки, но один источник). Все кнопки — только через токен, hex-коды в компонентах запрещены. Кнопка «Присоединиться» станет одного цвета со «Вступить в партию» автоматически.

**A4, отступы.** Ввести один утилитарный класс/переменную section-gap = 48px и применить ко всем секциям, вместо ручных py-16/py-24/py-32 в каждой. Это же чинит B2.

**C4, автоподсказки адреса.** Готовой бесплатной госбазы адресов РК с публичным API нет. Рабочий вариант — **2ГИС Suggest API**: лучшее покрытие казахстанских адресов, бесплатный тариф для старта, ключ оформить на заказчика. Запасной — Yandex Suggest. Если заказчик не захочет внешний API — откат на простой вариант: свободное поле + выбор города из справочника филиалов (как сейчас). В форме подсказки должны быть **необязательными**: не нашёл адрес в подсказках — вводит руками.

**C6, заявление-документ.** Блок заявления рендерится как «лист»: белый фон и чёрный текст жёстко, независимо от темы сайта (это документ, а не UI), шапка справа (кому/от кого), заголовок «Заявление» по центру, дата и город внизу. Тот же шаблон использовать для PDF-версии в письме.

**D3, партбилет при принятии.** Триггер меняется: письмо с сертификатом уходит не после подачи заявки, а **по событию смены статуса на «Принята»** (webhook на update). После подачи — только письмо «заявление принято к рассмотрению» с номером.

**F4, скрытие страниц.** Таблица pages (или расширение menu_items): slug, visible. Пункт меню скрывается, роут отдаёт редирект на главную. «Магазин» выключается первым — но данные и код не удаляются.

**H1, версия для слабовидящих.** Не сторонний виджет-костыль, а своя панель: переключатели «крупный шрифт (2 ступени) / высокий контраст / ч/б изображения / подчёркивать ссылки / отключить анимации», состояние в localStorage, реализация через классы на `<html>` поверх токенов темы — инфраструктура тем уже это позволяет.

   кнопка в хедере, язык хранится в `localStorage`

   версия открывается на корневом домене по умолчанию, русская — на
   `/ru`. Требует правок роутинга (`react-router-dom`) и, вероятно,
   nginx-конфига/SEO (проверить индексацию обеих версий).

   языка — но для блока `home_hero` (`app/src/sections/HeroSection.tsx`)
   казахские значения (`titleKz`, `subtitleKz`, `cta1LabelKz`,
   `cta2LabelKz`) не заполнены в БД, и блок не упомянут в
   `cms/packages/api/prisma/kz-content-sync.ts` / `docs/kz-missing.md`.
   Заполнить через CMS-админку (Страницы → Главная → блок `home_hero`) или
   добавить в `kz-content-sync.ts`.
